# Bruno Meyer — Professional Webpage (VitePress)

This repository contains a VitePress site generated from my CV.

## Run locally

- Install dependencies: `npm install`
- Start dev server: `npm run docs:dev`
- Build: `npm run docs:build`
- Preview build: `npm run docs:preview`

## Notes for GitHub Pages

If you deploy under a subpath (e.g. `https://<user>.github.io/<repo>/`), set VitePress `base` in `docs/.vitepress/config.mts` to `'/<repo>/'`.
